Reach for clast when the work touches the session journal: capturing
this or past agent sessions, curating what a session produced,
jotting a breadcrumb mid-task, or resurfacing prior context when the
user returns to a project (wake, brief, retro). Do not reach for it
to inspect the current conversation from inside — clast reads
persisted transcripts, and a session is captured from outside the
turn, by hook or on demand.
